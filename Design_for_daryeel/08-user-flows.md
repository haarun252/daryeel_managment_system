# Major User Flows

## School registration
Admin registers → Account → School → Onboarding → School settings → Classes/Subjects → Teachers/Staff → Fees/Transport → Dashboard.

## Teacher onboarding
Admin enters teacher → Teacher record → User invitation → Email + WhatsApp → Password setup → Assigned dashboard.

## Student registration
Admin creates student → Parent/Guardian → Class → Transport → Fee → Parent account/link → WhatsApp + Email → Student appears in class.

## Daily attendance
Teacher opens class → student list → Present/Absent/Late → Submit → Audit → Parent notification if enabled.

## Exam marks
Admin creates exam → Teacher enters marks → Submit → Review → Publish → Parent sees result → Notification.

## Student report
Teacher creates report → Draft → Submit → Review → Release → Parent notification.

## Fee
Admin creates monthly fee → Unpaid → Parent notification → Payment → Receipt → Paid/Partial → Finance ledger → Notification.

## Expense
Admin creates expense → category → amount → payee → reference → approval if required → ledger → dashboard.

## Transport
Create bus → route → driver → student assignment → pickup/drop-off → parent view.

## Promotion
Academic year ends → review → select students → promote → new enrollment → preserve history.
